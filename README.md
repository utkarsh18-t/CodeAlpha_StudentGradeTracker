# 🎓 CodeAlpha Task 1: Student Grade Tracker

A Java-based console application developed as part of the **CodeAlpha Java Development Internship**. This tool allows teachers or administrators to input student names and grades, store them dynamically, and generate a summary report.

---

## 🚀 Features

* 📥 **Dynamic Input:** Enter multiple student names and grades.
* 🛡️ **Input Validation:** Handles invalid numerical inputs, out-of-range grades (0–100), and empty names to prevent crashes.
* 📊 **Automated Calculations:**
  * Calculates class average score.
  * Identifies top performer (Highest Grade).
  * Identifies lowest score (Lowest Grade).
* 📝 **Clean Summary Report:** Displays a nicely formatted summary of results.

---

## 🛠️ Tech Stack & Concepts Used

* **Language:** Java
* **Data Structures:** `ArrayList<String>`, `ArrayList<Double>`
* **Core Concepts:** Loops (`while`, `for`), Conditionals (`if-else`), `Scanner` input handling, Methods, Exception Handling.
